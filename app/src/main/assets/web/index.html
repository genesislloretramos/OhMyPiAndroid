The agent running on this phone, on this device's own loopback address. Every app on a phone can reach that, so it wants this install's own token before it says anything. The notification has it, and so does web in the terminal.

The token is checked on every request except this page. It is not a defence against a rooted phone, or against someone who already has the URL: it is a defence against every other app on this device, and against any web page that happens to be open.
